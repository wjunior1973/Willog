Referência rápida

enquanto

Sintaxe

enquanto <condição>:
    <comandos>

Exemplo

n=0
enquanto n<10:
    n=n+1
mostre n
-> 10

n=0
enquanto n<10:
    n=n+1
mostre "n = {n}. Fim!"
-> n = 10. Fim!

intervalo

Sintaxe

(início..fim)
(início..fim,passo)

Exemplos

x=(1..5)
mostre x
-> 1,2,3,4,5

intervalo=(-5..5,2)
mostre intervalo
-> -5,-3,-1,1,3,5

leia

Sintaxe

<variável> = leia
<variável> = leia "mensagem"
<variável> = leia("mensagem")

Exemplo

nome = leia "Digite seu nome:"
mostre "Olá, {nome}!"
-> Digite seu nome: Wilson
-> Olá, Wilson!

idade = leia("Digite sua idade:")
mostre idade
-> Digite sua idade: 25
-> 25

mostre

Sintaxe

mostre <valor> [, <valor> ...]

Exemplos

mostre "Olá, mundo!"
-> Olá, mundo!

nome="Wilson"
mostre "Olá, {nome}!"
-> Olá, Wilson!

m=n=o=5
mostre m,n,o          -> 5, 5, 5
mostre m+n+o         -> 15
mostre m&n&o         -> 555

mostre { … }

Sintaxe

mostre {
    <expressão>
    <expressão> ...
}

Exemplo

A=[1,2,3]
mostre {
A
"A é uma lista"
}
-> 1, 2, 3
-> A é uma lista

para cada

Sintaxe

para cada <variável> entre <início> e <fim> [pulando <passo>]:
    <comandos>

para cada <variável> em <lista>:
    <comandos>

Exemplos

para cada x entre 1 e 5:
    mostre x
-> 1  2  3  4  5

para cada n entre 2 e 10 pulando 2:
    mostre n
-> 2  4  6  8  10

para cada letra em "willog":
    mostre letra
-> w  i  l  l  o  g

repetir

Sintaxe

repetir(<n>):
    <comandos>

Exemplo

repetir(4):
    mostre "Olá!"
-> Olá!
-> Olá!
-> Olá!
-> Olá!

se … senão

Sintaxe

se <condição>:
    <comandos>
senão:
    <comandos>

Exemplo

nota=8
se nota >= 7:
    mostre "Aprovado"
senão:
    mostre "Reprovado"
-> Aprovado

verificar … caso … padrão

Sintaxe

verificar <valor>:
    caso <valor>: <expressão>
    padrão: <expressão>

Exemplo

nota=9
verificar nota:
    caso 10: "Excelente!"
    caso 9: "Ótimo!"
    padrão: "Estude mais!"
-> Ótimo!
