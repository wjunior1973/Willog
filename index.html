Manual Willog

Willog 1.0 — Sintaxe • Exemplo • Saída

mostre

Sintaxe

mostre <valor> [, <valor> ...]

Exemplos

mostre "Olá, mundo!"
-> Olá, mundo!

nome="Wilson"
idade=53
mostre "Olá, {nome}! Você tem {idade} anos."
-> Olá, Wilson! Você tem 53 anos.

m=n=o=5
mostre m,n,o          -> 5,5,5
mostre m+n+o         -> 15
mostre m&n&o         -> 555
mostre "\n",m,"\n",n  -> (quebras)
5
5

mostre { … }

Sintaxe

mostre {
    <expressão>
    <expressão>
}

Exemplo

A=[1,2,3,4]
B=[3,4,5,6]
mostre {
    A+B
    A união B
    A intersecção B
    A-B
    B-A
}
-> 1,2,3,4,3,4,5,6
-> 1,2,3,4,5,6
-> 3,4
-> 1,2
-> 5,6

se … senão

Sintaxe

se <condição>:
    <comandos>
senão:
    <comandos>

Exemplos

a=5
b=10
se a>=b:
    mostre "a é maior ou igual a b"
senão:
    mostre "a é menor que b"
-> a é menor que b

nota=8
frequência=90
se nota>=7 e frequência>=75:
    mostre "Aprovado"
senão:
    mostre "Reprovado"
-> Aprovado

verificar … caso … padrão

Sintaxe

verificar <valor>:
    caso <valor>: <expressão>
    caso <valor>: <expressão>
    padrão: <expressão>

Exemplo

nota=9
verificar nota:
    caso 10: "Parabéns! Excelente!"
    caso 9: "Ótimo!"
    caso 8: "Muito bom!"
    padrão: "Estude mais!"
-> Ótimo!

valor=500
verificar valor:
    caso 100: "Muito pouco!"
    caso 200: "Pouco!"
    padrão: "Muito!"
-> Muito!

para cada

Sintaxe

para cada <var> entre <ini> e <fim> [pulando <passo>]:
    <comandos>

para cada <var> em <lista/texto>:
    <comandos>

Exemplos

para cada x entre 1 e 5:
    mostre x
-> 1
-> 2
-> 3
-> 4
-> 5

para cada número entre 2 e 10 pulando 2:
    mostre número
-> 2
-> 4
-> 6
-> 8
-> 10

para cada letra em "willog":
    mostre letra
-> w
-> i
-> l
-> l
-> o
-> g

a=[1,2,3,4,5,6]
para cada item em a:
    mostre item
-> 1
-> 2
-> 3
-> 4
-> 5
-> 6
